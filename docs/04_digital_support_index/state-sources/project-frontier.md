# Project Frontier — legacy name

## Current interpretation

`Project Frontier` is retained only as a compatibility/navigation name.

There is no separate canonical Project Frontier database.

For current weekly work, use a **front view** compiled from governed sources such as:

- `front_registry_v2`;
- `carry_state_v2`;
- relevant Office v2 work/preparation artifacts.

## Why the name remains

Older route cards use Project Frontier to mean “the wider universe of possible fronts, not just the current active subset.”

That idea is still useful. The implementation is now a query/view rather than a separate state store.

## Used by

- CARRY-W
- PROJECT-TRIAGE
- QUARTERLY-REFRAME
- BREAKTHROUGH-14D

These routes may consume a front view without writing to it.

## Future direction

A published `front_portfolio` or similar read contract may replace this compatibility page. The view must remain reproducible from governed state.
